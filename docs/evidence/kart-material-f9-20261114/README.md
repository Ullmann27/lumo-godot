# Isolierter Kart-Folgeanschluss auf Native f9

Dieser Quellcheckpoint verbindet ausschließlich zehn Fahrzeug-/Rivalenpfade
aus den exakt gebundenen PR-183-/PR-184-Quellen mit dem vorhandenen Native-f9-Baum.
Die neue Aero-Ergänzung vereinheitlicht zwei zusätzliche Materialschlüssel;
Geometrie, Farben und die bisherigen Material-/LOD-Grenzen bleiben erhalten.
Die Änderung an Metallanteil und Leuchtstärke ist ausgewiesen und wird nicht
als identisches Bild oder bereits eingehaltenes Gesamtbudget ausgegeben.

Der ursprüngliche Vehiclelauf des Producerstands scheiterte an den bestehenden
Oberflächengrenzen. Dieser neue Checkpoint ist vor einer tatsächlichen lokalen
Engineprüfung gespeichert. Weder ein erfolgreicher Vehiclelauf noch Geräte-FPS
oder Android-Abnahme werden behauptet. Die vorhandenen Vehicle-/Physics-/Coastal-
Grenztests bleiben unverändert. Die kleinere Rabbit-Augenform ist eine explizite
Producer-Designänderung mit zugehörigem ursprünglichem Proportionstest.

Strecken, Tunnel, modulare Straßenobjekte und Ring-/Itemänderungen sind wegen
konkreter, separat dokumentierter Vertragskonflikte nicht Teil dieser Übernahme.
Die übrigen 3754 vorherigen Pfade bleiben unverändert. Der aktive Host fa5e8695
und sein exakt gebundener Native-Pin f9 werden durch diesen isolierten Zweig
nicht verändert. Der aktuelle vollständige APK-Lauf bleibt eigenständig.
