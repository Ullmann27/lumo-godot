# Design Brief — Volcano Night Run

Creative direction: preserve the current Opus racing visual language. Use the hero art as the anchor and translate it into modular 3D scene construction.

World theme: lava canyon at night with molten rivers and fiery loop
World ingredients: lavafalls, black rock spires, glowing magma, night sky
Gameplay tone: fast, exciting, child-friendly, readable, premium.
Signature features: lava loop, magma ramps, crown beacons, reflective night roadway
Hazard approach: heat zones, narrow bridges over lava, visual pressure, fast night turns
Learning integration: courage and persistence motif with dramatic spectacle
