# Design Brief — Desert Dune Drift

Creative direction: preserve the current Opus racing visual language. Use the hero art as the anchor and translate it into modular 3D scene construction.

World theme: desert canyon with ruins, oasis, statues and high-speed drift roads
World ingredients: sandstone canyons, oasis water, statues, desert bridges, loop gate
Gameplay tone: fast, exciting, child-friendly, readable, premium.
Signature features: desert loop, drift corners, oasis bridge, statue corridor
Hazard approach: dust, long drifts, loose traction, sun glare, cliff descents
Learning integration: history and exploration styling with ancient wonder cues
