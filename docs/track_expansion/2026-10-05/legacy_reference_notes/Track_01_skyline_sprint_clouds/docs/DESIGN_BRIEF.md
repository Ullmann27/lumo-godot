# Design Brief — Skyline Sprint

Creative direction: preserve the current Opus racing visual language. Use the hero art as the anchor and translate it into modular 3D scene construction.

World theme: floating futuristic city above the clouds
World ingredients: sky city, waterfalls, floating islands, neon bridges, sky loop, elevated roadways
Gameplay tone: fast, exciting, child-friendly, readable, premium.
Signature features: large skyline loop, banked cloud-road curves, mid-air bridges, turbo ramp, skyline billboards
Hazard approach: edge pressure, wind gust feel, tight high-speed curves, long loop sections
Learning integration: city districts linked to subject zones and curiosity banners
