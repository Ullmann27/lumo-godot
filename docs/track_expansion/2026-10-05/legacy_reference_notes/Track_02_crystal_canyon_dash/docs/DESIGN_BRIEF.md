# Design Brief — Crystal Canyon Dash

Creative direction: preserve the current Opus racing visual language. Use the hero art as the anchor and translate it into modular 3D scene construction.

World theme: crystal canyon with waterfalls and glowing caverns
World ingredients: rock canyons, giant crystals, crystal cave tunnel, cliff bridges, waterfalls
Gameplay tone: fast, exciting, child-friendly, readable, premium.
Signature features: crystal loop, glowing cave entrance, booster ramp, suspended bridges
Hazard approach: narrow cliff turns, crystal choke points, cave darkness transitions
Learning integration: discovery theme with geology and exploration styling
