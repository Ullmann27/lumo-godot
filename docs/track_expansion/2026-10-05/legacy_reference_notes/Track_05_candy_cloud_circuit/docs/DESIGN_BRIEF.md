# Design Brief — Candy Cloud Circuit

Creative direction: preserve the current Opus racing visual language. Use the hero art as the anchor and translate it into modular 3D scene construction.

World theme: candy cloud kingdom with dessert islands and a donut loop
World ingredients: cotton-candy skies, frosting roads, cookie islands, candy castles
Gameplay tone: fast, exciting, child-friendly, readable, premium.
Signature features: donut loop, frosting curves, marshmallow props, rainbow connectors
Hazard approach: sticky corners, playful bounce pads, narrow rainbow lanes
Learning integration: gentle entry track for younger players with clear readable landmarks
