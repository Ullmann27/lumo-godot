# Design Brief — Jungle Temple Turbo

Creative direction: preserve the current Opus racing visual language. Use the hero art as the anchor and translate it into modular 3D scene construction.

World theme: lush jungle temple world with waterfalls and rope bridges
World ingredients: jungle foliage, temple gates, vine-covered ruins, torches, rope bridges
Gameplay tone: fast, exciting, child-friendly, readable, premium.
Signature features: temple gate focal point, jump ramp, rope bridge traversal, jungle obstacle set
Hazard approach: swinging logs, stone rollers, narrow wood bridges, blind jumps
Learning integration: exploration and discovery theme with jungle puzzle motifs
