# Design Brief — Learning Lab Circuit

Creative direction: preserve the current Opus racing visual language. Use the hero art as the anchor and translate it into modular 3D scene construction.

World theme: futuristic learning campus with science, math, creativity, reading and quiz zones
World ingredients: subject towers, branching lanes, puzzle gates, holograms, waterfalls
Gameplay tone: fast, exciting, child-friendly, readable, premium.
Signature features: quiz zone gate, puzzle path split, learning icon loop, subject districts
Hazard approach: branch decisions, busy signage, split path timing, modular subject events
Learning integration: main progression showcase track connecting racing to school progress
