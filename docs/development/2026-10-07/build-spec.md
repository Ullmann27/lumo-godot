# Bauwelt

Reference: lumo_bauwelt_creative_build_board.webp, 2026-10-05. Actual 3D meshes and physics, 33×33 editable grid, river separating banks. Twenty-eight construction pieces retain dimensions/colliders; camera orbit/zoom/tilt/pan, rotating placement, snapping, removal, undo/redo, six save slots, templates and six checkable challenges. Structural support and overlapping volumes are validated before each placement. A bridge test needs a continuous connected deck over the river; a house needs supporting walls, a door and a roof; a tower needs height and a light. Castle and village combine those structures; the garden needs different useful plant/decorative parts. No generic building-count rewards. IDs persist per child and goal across slots to avoid repeat rewards after reload. The integrated Flutter host supplies an opaque, salted per-profile childKey. Atomic JSON saves retain the camera and completed challenges.

No fully rigged GLB exists in the current source. Existing animated Lumo is preserved for race; no new primitive fox replaces the reference character. Bauwelt uses a glowing star as the construction/path indicator while the production character remains VISUAL_GAP.
