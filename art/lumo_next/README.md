# Editable production sources

These Blender files and scripts were frozen from Chat 3’s actual working tree. The character production manifest matches the integrated runtime GLB byte for byte; all 15 learning GLBs match the source manifest. Exact file hashes and producer provenance are recorded in `docs/nextgen/evidence/avatar-authoring-snapshot-01.json`. The producer files were not committed at capture; the integration commit is the durable source record.

`.gdignore` keeps authoring files out of Godot import and the Android export. The runtime uses the checked GLB assets, not a second Blender import. Generated review scenes and source-only protocol drafts are not the integration contract. `docs/nextgen` and the actual protocolVersion 1 adapters define the current task, turn, audio and cancellation boundary.

The character retains the original orange-white fox, blue goggles and dark-blue jacket. The blend includes the rig, mouth poses and authored clips. Pose availability is not phoneme-timing evidence. Physical Android/Fold performance and actual microphone behavior require their own device evidence.
