# Lumo Kart menu art

The SVG action illustrations are original project artwork, authored as native
vectors for this menu. No external icons, characters or game logos are used.

`lumo-world.webp` reuses the existing Lumo app artwork from
`lumo-lernen/assets/lumo_design/bg/bg_kart.png`, converted to WebP for size.
It is a menu background, never used as a screenshot of the running game.

Menu and HUD use the exact Nunito Bold and Black font files already shipped by
the Flutter app. Nunito's existing OFL license is in `assets/fonts/`.
